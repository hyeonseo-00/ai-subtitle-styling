# AI Subtitle Styling — 청각장애인을 위한 감정 기반 자막 스타일링 TV 서비스

> LG전자 DX School 3기 DX 프로젝트 · 2025.11 ~ 2025.12 · 4인 팀 프로젝트
> **13팀 중 1위(대상) 수상 · 실시간 감정 자막 MVP 시연 · 사용자 테스트 만족도 95%**

말소리를 자막으로 옮길 때 감정, 목소리 세기, 화자, 배경음을 함께 시각화해서 청각장애인이 소리 없이도 장면의 분위기와 맥락을 이해할 수 있게 한 webOS TV용 자막 서비스입니다.

> 이 저장소는 포트폴리오 열람을 위해 비공개 팀 저장소의 코드만 옮긴 공개 사본입니다. 커밋 히스토리, API 키, 크롤링한 원본 데이터(커뮤니티 게시글 등)는 저작권·개인정보 보호를 위해 제외했습니다.

## 문제에서 해결까지

1. **데이터로 문제 찾기**: 국내외 9개 채널(네이버, 유튜브, Reddit 등)에서 청각장애인의 발화 데이터 약 2.1만 건을 수집했습니다. KO-BERT와 Doc2Vec의 군집화 결과를 비교한 뒤 Doc2Vec으로 문제 후보 4개를 도출했고, 그중 **TV 자막**을 핵심 문제로 선정했습니다.
2. **문제 구체화**: 정성 분석 결과, 일반 자막으로는 **감정 · 화자 · 상황** 정보가 전달되지 않는다는 점이 드러났습니다.
3. **기회 발견**: YouTube, Netflix, Disney+, Apple TV, Samsung Tizen, LG webOS를 비교한 결과, 모두 "읽기 쉬운 자막"에 머물러 있고 "감정을 전달하는 자막"은 빈 시장이었습니다.
4. **해결 방향**

| 기능 | 내용 |
|---|---|
| 감정 색상 | Plutchik 감정 모델과 128년간의 색채-감정 연구를 근거로 7개 감정을 색상 3단계와 이모지로 매핑 |
| 소리 높낮이 | RMS로 목소리 세기를 측정해 자막 크기를 3단계로 조절 |
| 화자 구분 | Deepgram diarization으로 화자를 분리하고, 스포일러 없이 `[인물1]`·`[인물2]`로 익명 표기 |
| 배경음/효과음 | PANNs로 BGM과 효과음을 감지해 `🎵 [BGM]`·`🎧 [효과음]` 태그로 표시 |
| 쉬운 접근 UX | 유형 모드, 퀵모드 패널, ThinQ 리모컨 모드로 설정 메뉴를 거치지 않고 바로 사용 |

**AI 파이프라인**: 오디오 입력 → STT(Deepgram, faster-whisper와 비교 후 선정) → 문장 정리(kiwipiepy) → 감정 분석(klue/bert-base) → 세기 계산(RMS) → BGM/SFX 감지(PANNs) → 자막 JSON 생성
